## 四、 萬物與測事應用歌訣

### 1. 諸事響應歌
> 體旺事成衰事敗，用生體者有財來。
> 體生用者多耗散，用克體時災禍催。
> 體克用時雖可喜，須知費力亦難為。
> 比和吉事無差忒，互變之中仔細推。

### 2. 應期推斷心法
- **體旺逢生**：應期通常較速。
- **體衰被克**：應期較遙遠或成就難度大。
- **動中占**：數值通常減半。
- **靜中占**：數值通常加倍。

## 五、 測字法 (字占)

測字以漢字的編排、意涵為核心，結合拆字技法推斷天機。

### 1. 六神與筆形
| 六神 | 筆形特徵 | 主象 |
| :--- | :--- | :--- |
| **青龍** | 撇捺長形 | 喜事、成功、利木 |
| **朱雀** | 尖短交叉 | 文書、口舌、屬火 |
| **螣蛇** | 長曲如蛇 | 虛驚、怪異、化火 |
| **勾陳** | 彎弓斜月 | 羈滯、田產、屬土 |
| **白虎** | 尾尖口闊 | 疾病、凶兆、化金 |
| **玄武** | 方尖內收 | 盜賊、私欲、化水 |

### 2. 測字技法整理
- **增筆法**：在大字中加一點為「太」或「犬」。
- **減筆法**：將「問」字去口為「門」。
- **拆分法**：將「解」字析為角、刀、牛。
- **合併法**：將木、目合併為「相」。
- **諧音法**：利用同音異義字進行聯想分析。

> 「字乃心畫，心動而字成。觀字如觀心，察字如察意。」
