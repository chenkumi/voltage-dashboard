本表基於 384 爻數據分析，為每個卦象定義了特定的戰略類型。

> **核心哲學**：易 = 變。能隨時而變則吉，固步自封則凶。

---

## 一、 策略類型定義

| 類型 | 描述 | 建議策略 |
| :--- | :--- | :--- |
| **吸引子** | 自己當下好，變動後變差。 | **留**：守住現狀，避免盲動。 |
| **排斥子** | 自己當下差，變動後可轉好。 | **走**：主動求變，尋求突破。 |
| **福地** | 整體吉率較高且穩定。 | **守**：在此深耕。 |
| **困境** | 整體吉率極低，處於低谷。 | **變**：窮則變，變則通。 |
| **陷阱** | 自己差，周遭鄰居也差。 | **慎**：步步為營，慎防連環災。 |
| **一般** | 中等水平。 | **觀**：靜待時合，以觀其變。 |

## 四、 關鍵指標：臨卦轉折點
- **特性**：二陽在下、四陰在上，象徵貴人降臨。
- **效應**：變成臨卦時地位能提升 **+0.83**；離開臨卦時地位能下降 **-0.83**。

## 五、 應用步驟
1. **得本卦**：確認當前所處環境的吉率與類型。
2. **定策略**：根據類型表決定是「守」還是「變」。
3. **查路徑**：若需「變」，尋找能轉化為高吉率變卦的動爻作為行動指引。
4. **守時義**：任何策略必符合當下的理法。
