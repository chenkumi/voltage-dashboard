# 十八類分占法

《梅花易數》卷二詳述十八種專門占法，針對人生各類事務提供具體斷卦指引。

> 上為用體之訣，始發十八章佔例，以示後學之法則。然庶務之多，豈止十八佔而已乎！然此十八佔，乃大事之切要者，佔者以類而推之可也。

---

## 通用原則

**體用基本法則：**
- **體為主**：問卦者、自己。
- **用為事**：所問之事、對象。
- **吉凶判斷**：
  - 用生體及比和則吉。
  - 體生用及用克體則不吉。

---

## 第一類：天時占
主要用於占察天氣與氣象變化。

### 1. 斷法表
| 卦象 | 天氣 | 狀態 |
| :--- | :--- | :--- |
| **乾** | 晴明 | 天朗氣清 |
| **坤** | 陰晦 | 雲厚陰沈 |
| **離** | 晴熱 | 主晴、火熱 |
| **坎** | 雨雪 | 霜露、冰雹 |
| **震** | 雷鳴 | 驚雷動地 |
| **巽** | 風 | 風起之象 |
| **艮** | 山氣 | 久雨將晴 |
| **兌** | 陰潤 | 不雨亦陰 |

### 2. 詳訣
- **主從關係**：離多主晴，坎多主雨；坤乃陰晦，乾主晴明。
- **季節差異**：震卦多於春夏之時則雷鳴。
- **生克應用**：若卦有生體之象則雨也晴；克體則陰雨。

---

## 第二類：人事占
主要用於占察人事吉凶與行事成敗。

### 1. 核心邏輯
- 體卦為主，用卦為賓。
- 詳觀體用生克，並參照互卦、變卦之演化。

### 2. 應用策略
- **生體之卦**：以所生之卦取其吉象。
- **克體之卦**：以所克之卦取其凶象。
- 結合八卦類象，推斷具體與何人、何事相關。

---

## 第三類：家宅占
主要用於占察家運與宅運興衰。

### 1. 斷語對照
| 關係 | 斷語 |
| :--- | :--- |
| **體克用** | 家宅多吉 |
| **用克體** | 家宅多凶 |
| **體生用** | 多耗散，防失盜 |
| **用生體** | 家道興隆 |
| **體用比和** | 平安吉利 |

### 2. 細部論斷
- **成員對應**：乾為父、坤為母、震為長男、巽為長女。
- 可依據爻位推斷家中特定成員的吉凶。

---

## 第四類：屋舍占
主要用於占察居住環境與房屋本身的吉凶。

| 關係 | 斷語 |
| :--- | :--- |
| **體克用** | 居之吉 |
| **用克體** | 居之凶 |
| **體生用** | 主資財耗散 |
| **用生體** | 門戶興隆 |

*註：體卦代表居者，用卦代表屋舍。*

---

## 第五類：婚姻占
主要用於占察姻緣成敗與婚配質量。

### 1. 斷語表
| 關係 | 斷語 |
| :--- | :--- |
| **用生體** | 婚易成，或因婚有得 |
| **體生用** | 婚難成，或因婚有失 |
| **體克用** | 可成，但成就較遲 |
| **用克體** | 不可成，成亦有害 |
| **體用比和** | 婚姻吉利 |

### 2. 類象推斷（資貌品性）
- **乾**：為老翁、**坤**：為老婦。
- **震**：為長男、**巽**：為長女。
- **坎**：為中男、**離**：為中女。
- **艮**：為少男、**兌**：為少女。

---

## 第六類：生產占
主要用於占察生育狀況與母子安危。

### 1. 生產順逆
- **體用俱旺**：產易，過程順利。
- **體用俱衰**：產難，需多加註意。

### 2. 性別判斷
- **男**：陽卦陽爻多者，或陰卦多陽者。
- **女**：陰卦陰爻多者，或陽卦多陰者。

### 3. 吉凶判斷
- **體克用**：不利於子。
- **用克體**：不利於母。

---

## 第七類：飲食占
主要用於占察宴飲質量與飲食所得。

| 關係 | 斷語 | 類象補充 |
| :--- | :--- | :--- |
| **用生體** | 飲食必豐 | 坎：主酒、湯水 |
| **體生用** | 飲食無味 | 兌：主食、口福 |
| **用克體** | 飲食必無 | 離：主熟食、烹調 |
| **體克用** | 飲食難求 | 艮：主穀物、果蔬 |

### 1. 斷語表
| 關係 | 斷語 |
| :--- | :--- |
| **用生體** | 名易成 |
| **體用比和** | 功名順遂 |

---

## 第十類：求財占
主要用於占察財運、投資與生意盈虧。

### 1. 基本斷法
- **用生體 / 體克用**：有財可得。
- **體生用 / 用克體**：財難求，耗費多。
- **體用比和**：財利遂意。

### 2. 應期判斷
- 依據卦氣旺衰決定得財時間。
- 體旺則財來速，體衰則財來遲。

## 第十六類：疾病占
主要用於占察病情走向與健康狀況。

### 1. 核心指標
- 體為病人，用為病症。
- 體卦宜旺不宜衰，宜逢生不宜見克。

### 2. 斷語表
| 關係 | 斷語 |
| :--- | :--- |
| **用生體** | 即愈 |
| **體克用** | 勿藥有喜 |
| **體生用** | 病難愈 |
| **用克體** | 雖藥無功 |

### 3. 病因類象
- **乾**：頭病、骨病。
- **坤**：腹病、脾胃。
- **震**：足病、肝病。
- **巽**：股病、風症。
- **坎**：耳病、腎病、血病。
- **離**：眼病、心病。
- **艮**：手病、背病。
- **兌**：口病、肺病。

## 延伸應用
> 「庶務之多，豈止十八佔而已乎！佔者以類而推之可也。」

其他現代事務可依此十八類邏輯延伸推廣：
- **合作經營**：參考交易占、婚姻占。
- **金融投資**：參考求財占、交易占。
- **健康檢查**：參考疾病占。
- **職位面試**：參考求名占、謁見占。
- **搬遷居住**：參考家宅占、屋舍占。
