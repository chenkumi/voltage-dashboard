# 卦象關係深度指南

本文件詳述六種核心卦象關係：**應、承乘、互卦、錯卦、綜卦、變卦**，並結合周易 384 爻統計分析，提供精準的解卦維度。

---

## 一、 快速參考：六種關係的作用

| 關係 | 定義 | 核心功能 | 適用場景 |
| :--- | :--- | :--- | :--- |
| **應** | 初與四、二與五、三與上的呼應 | 判斷是否有外援 | 尋求合作、問貴人、求助 |
| **承乘** | 相鄰兩爻的上下位置關係 | 判斷人際/權力結構 | 職場關係、輩分衝突 |
| **互卦** | 由本卦第 2, 3, 4, 5 爻組成 | 窺視事情的內在本質 | **每次必看**，分析中間過程 |
| **錯卦** | 陰陽完全相反的對稱卦 | 提供互補視角 | 尋求不同角度的思考 |
| **綜卦** | 180 度上下倒置的倒影卦 | 模擬對方的視角 | 談判、感情糾紛、競爭者心態 |
| **變卦** | 動爻由陽變陰或陰變陽後之卦 | 預示事情的最終走向 | 有動爻時的最終依據 |

---

## 二、 核心關係詳解

### 1. 應 (對應爻) — 判斷外緣助力
- **規則**：
  - **有應** (一陰一陽)：有資源到位，事半功倍。
  - **無應** (同陰或同陽)：需自立更生，缺乏外部支持。
- **統計吉率**：
  - **二 ↔ 五 (君臣應)**：吉率 68.8% (影響力最高)。
  - **初 ↔ 四**：吉率 46.9%。
  - **三 ↔ 上**：吉率 34.4%。

### 2. 承乘 — 判斷權力結構
- **乘**：上位爻騎在下位爻之上。
- **承**：下位爻支撐上位爻。
- **關鍵組合**：
  | 類型 | 吉率 | 象徵意義 |
  | :--- | :---: | :--- |
  | **陽乘陰** | 43.8% | 剛健統帥柔順，最為順遂。 |
  | **陰乘陽** | 22.5% | 柔弱凌駕剛強，最為險惡 (凶)。 |

### 3. 互卦 — 洞察事情本質 (重要係數: 0.73)
- **結構**：
  - **下互** (2, 3, 4 爻) 形成內卦。
  - **上互** (3, 4, 5 爻) 形成外卦。
- **核心價值**：互卦是判斷事情「發展過程」及「隱藏矛盾」的最強指標。

### 4. 變卦 — 趨勢演化
- **384 爻變化規律**：
  - **陰爻動**：吉率 41.1% (變動通常較為安全)。
  - **陽爻動**：吉率 35.9% (陽極必反，需謹慎)。
- **位能分析**：
  - **三爻動**：雖本處凶地，但變化後最易轉好 (窮則變，變則通)。
  - **二五爻動**：本處尊位，變動後吉率反而下降 (宜守不宜動)。

## 三、 五行通關與化解

當體用相克時，若互卦或變卦中含有「通關元素」，可緩解凶象。

### 通關對照表
| 克關係 | 通關元素 | 原理 | 卦象演進 |
| :--- | :---: | :--- | :--- |
| **金克木** | **水** | 金生水，水生木 | 乾兌 → 坎 → 震巽 |
| **木克土** | **火** | 木生火，火生土 | 震巽 → 離 → 坤艮 |
| **土克水** | **金** | 土生金，金生水 | 坤艮 → 乾兌 → 坎 |
| **水克火** | **木** | 水生木，木生火 | 坎 → 震巽 → 離 |
| **火克金** | **土** | 火生土，土生金 | 離 → 坤艮 → 乾兌 |

## 四、 完整解卦公式

> **最終結果 = 本卦 (現狀) + 動爻 (轉折) + 變卦 (最終) + 互卦 (本質) + 應爻 (外援) + 時理 (背景)**

### 權重比例建議：
1. **時義與時令** (40%)：大環境主題。
2. **動爻位能** (25%)：變化的爆發點。
3. **互卦本質** (15%)：事情的水面下秘密。
4. **體用生克** (15%)：基本的得失結果。
5. **其餘關係** (5%)：點綴細節。
