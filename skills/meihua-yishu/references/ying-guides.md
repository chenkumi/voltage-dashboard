# 十應詳解與外應指南

本指南整合「十應」系與「外應」核心心法，旨在協助占者由耳目所得，補卦象之不足。

---

## 一、 十應總論
「十應」即占卦時周遭環境的十種反應。

| 原則 | 說明 |
| :--- | :--- |
| **內不吉外吉** | 外應可以解救內卦之凶兆。 |
| **內吉外不吉** | 好的卦象會被壞的外應破壞。 |
| **內外皆吉** | 斷然大吉。 |
| **內外皆凶** | 斷然大凶。 |

---

## 二、 十應分類詳解

### 1-5 類：自然與方位
| 類別 | 觀察點 | 吉凶轉化建議 |
| :--- | :--- | :--- |
| **天時之應** | 晴、雨、雷、電 | 逢生體卦之天象為佳。例：坎體逢雨。 |
| **地理之應** | 山、水、林、屋 | 環境之五行應生扶體卦。 |
| **人事之應** | 走動、笑語、哭泣 | 推斷人際助益。笑主喜，哭主憂。 |
| **時令之應** | 季節、節氣 | 體卦當令 (春木、夏火) 則事易成。 |
| **方卦之應** | 事物來去方向 | 吉象從生方來加吉，凶象從克方來加凶。 |

### 6-10 類：萬物與感官
| 類別 | 對應卦象 | 現代解析 |
| :--- | :--- | :--- |
| **動物之應** | 馬(乾)、雞(巽)、狗(艮) | 觀察動物的動向與神態。 |
| **靜物之應** | 圓(乾)、方(坤)、破(兌) | 見完整物為吉，見缺損物主是非。 |
| **言語之應** | 聽聞好話/壞話 | 偶然聽見的對話關鍵詞往往是應期。 |
| **聲音之應** | 鐘聲、雷聲、喇叭聲 | 悅耳聲吉，雜亂刺耳聲凶。 |
| **五色之應** | 五行顏色 | 體卦喜見生扶之色。例：震木喜綠、黑。 |

## 三、 三要心法 (眼、耳、心)

邵康節觀物取象之精髓：
- **眼要**：最直接的視覺外應。
- **耳要**：透過聲音定位空間與狀態。
- **心要**：直覺與第一感官震顫。

## 四、 現代生活中的外應來源

| 現代場景 | 卦象轉化建議 |
| :--- | :--- |
| **手機通知** | 消息內容即為卦義補充。 |
| **車牌號碼** | 突現的數字可用於定應期或起卦。 |
| **廣告標語** | 映入眼簾的第一句話通常指點迷津。 |
| **背景音樂** | 歌詞的意境往往反映當下的心理戰場。 |

## 五、 外應取捨原則

### ✅ 應取：
- 起卦瞬間發生的**異常現象**。
- 自然發生、非人為刻意安排的信號。
- 第一時間感應最強烈的徵兆。

### ❌ 捨棄：
- 刻意去尋找或人為製造的標誌。
- 常態性、無任何獨特性的背景噪音。
- 過度牽強附會的聯想。
