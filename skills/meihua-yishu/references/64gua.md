## 三、 動爻位置意義

| 動爻 | 階段 | 時機判斷 |
| :--- | :--- | :--- |
| **初爻** | 萌芽 | 事情剛開始，地位卑微或力量不足。 |
| **二爻** | 發展 | 處於內卦中位，得地利，多主吉祥。 |
| **三爻** | 轉折 | 內卦之極、外卦之始，多凶多懼。 |
| **四爻** | 過渡 | 近君之位，多憂慮，需小心謹慎。 |
| **五爻** | 高峰 | 君位，九五之尊，事業達到頂峰。 |
| **上爻** | 終結 | 事情之終局，物極必反，防衰落。 |
