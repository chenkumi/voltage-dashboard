### BUG-001: 完整測試 suite 存在 suite-level 非決定性失敗，且預設執行無法在合理時間完成
- 嚴重度: S2-2
- 資安相關: 否
- 位置: `src/app/webmcp/products/product-pages.test.tsx:219-244`（商品排序 UI test）；`package.json:12`（`test` script）
- 描述: 以單工限制執行完整測試 suite 時，73 個 test files／647 個 tests 中有 1 個失敗：商品列表排序流程預期套用「Price high–low by currency」後看到 Product 16，但實際 DOM 只顯示 Product 1–15。失敗輸出顯示實際 active sort 為「Stock low–high」。同一測試檔單獨執行 17/17 通過，表示失敗與 suite 執行順序、共享狀態或互動時序有關，不能視為穩定的產品排序功能缺陷。第一次直接執行 `npm run test` 超過 4 分鐘沒有結果，已中止；受控單工執行才完成並暴露上述 assertion failure。
- 重現步驟:
  1. 執行 `npx vitest run --reporter=verbose --maxWorkers=1 --testTimeout=10000 --hookTimeout=10000`。
  2. 觀察完整 suite 在 `product-pages.test.tsx` 的「applies product sorting from More and resets pagination」失敗，錯誤為找不到 Product 16。
  3. 再單獨執行 `npx vitest run src/app/webmcp/products/product-pages.test.tsx --reporter=dot`，觀察同一檔案 17/17 通過。
- 可重現等級: T1
- 受影響範圍: 1 個 UI test flow；完整 CI／本地測試 gate
- 驗證結果: 已確認（完整 suite 中重現；隔離檔案可通過）
- 備註: 分類不完全貼合，建議補類「測試隔離／互動時序穩定性」。與上一輪 BUG-008 表面相似但根因不同：BUG-008 是 Inventory／Orders 長流程 deadline timeout，本項是 Products sorting assertion 在完整 suite 中的狀態／時序差異。

### BUG-002: production dependency tree 含 npm 及其高風險巢狀漏洞
- 嚴重度: S2-4
- 資安相關: 是
- 位置: `package.json:25,29`（runtime dependencies 的 `install` 與 `npm`）；`package-lock.json` 對應巢狀 dependency

- 重現步驟:
  1. 在專案根目錄執行 `npm audit --omit=dev --audit-level=high`。
  2. 觀察命令以 exit code 1 結束並回報 5 個漏洞，其中 4 個為 high。
  3. 檢查 `package.json`，確認 `npm` 與 `install` 位於 `dependencies` 而非必要的 build tooling。
- 可重現等級: T1
- 受影響範圍: production dependency tree、安裝流程與公開安全稽核
- 驗證結果: 已確認
