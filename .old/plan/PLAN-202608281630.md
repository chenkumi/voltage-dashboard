# Plan

本計畫將移除 URL 上的 `threadId`，讓 `/` 成為 Assistant host，並讓 `/market`、`/dashboard` 成為可被 iframe 載入的 WebMCP demo 頁面。系統會透過 `siteProfiles` 建立 URL 與 `siteId` 的對應，再依 `siteLastThreads` 恢復每個網站最後使用的對話。

> 本計畫請使用 execute-plan 技能執行。此次會直接刪除舊 IndexedDB 資料，因此不做舊資料 migration，也維持 Dexie schema version 1。

## Scope

### In

- `/` 顯示 `Assistant`
- `/market` 顯示 Market demo
- `/dashboard` 顯示 Dashboard demo
- iframe 改載入 `/market`、`/dashboard`
- 新增 `siteProfiles` table
- 初始化建立 URL、siteId、名稱對應
- `useLiveQuery` 改為依據 `url → siteId → siteLastThreads → thread`
- threadId 不再出現在瀏覽器 URL
- New Thread 與切換網站後即時切換畫面
- 保留每個 thread 的 `siteId + url` 目標快照
- 新增資料層、路由與 IndexedDB persistence 測試

### Out

- Site 管理 UI
- 後端或 API
- 舊 IndexedDB 資料 migration
- 跨來源 iframe 整合
- 個資、付款與高風險 WebMCP 流程變更
