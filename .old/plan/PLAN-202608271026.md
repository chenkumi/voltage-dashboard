# Plan

將 Chat Room 改為「持久化完整訊息、記憶體暫存 assistant 串流」的資料生命週期，並以已存在的 `[threadId+id]` 索引提供 TanStack Virtual 所需的排序 ID 清單。完成後，開啟長對話不再先載入所有 `UIMessage` 內容到畫面；使用者訊息送出即保存，未完成的 assistant 回覆則不會污染 IndexedDB 或下一輪模型 context。

> 本計畫請使用 execute-plan 技能執行。Checkbox（`- [ ]`）語法為追蹤格式。

## Scope

- In:
  - 使用 `@tanstack/react-virtual` 改造 Chat Room 訊息渲染。
  - 維持 `messages` 為唯一持久化來源，以既有 `[threadId+id]` 讀取排序後的 primary keys。
  - user message 送出即寫入 IndexedDB。
  - assistant 串流只存在記憶體；正常完成才持久化。
  - stop、error、disconnect、切換 thread 時捨棄未完成 assistant，並排除下一輪模型 context。
  - 以單元測試與瀏覽器操作驗證資料生命週期、捲動及 persistence 行為。

- Out:
  - 新增 `session_message_index`／`thread_message_index` table。
  - IndexedDB 舊資料 schema migration。
  - 歷史訊息分頁、LLM context 壓縮或 token budget 政策。
  - 重新設計訊息 UI、WebMCP iframe 或模型設定。

## Files

- `src/app/assistant/chat-store.ts`：提供訊息 ID 清單、單筆訊息讀取及單筆完整訊息持久化操作。
- `src/app/assistant/chat-message-state.ts`：新增純函式，管理 persisted/live row 合併、去重與 aborted assistant 排除。
- `src/app/assistant/chat-message-state.test.ts`：驗證訊息生命週期與 row 資料模型。
- `src/app/assistant/index.tsx`：調整 `useChat`、立即保存 user、正常完成保存 assistant，以及取消時清除暫存 context。
- `src/app/assistant/chat-window.tsx`：以 TanStack Virtual 呈現 persisted 與 temp message rows。
- `src/components/ui/scroll-button.tsx`：改為接受 Virtualizer 的「是否在底部」與「跳到最新」能力，不再依賴 `use-stick-to-bottom` context。
- `src/app/webmcp/transport.ts`：接收由 Chat Session 注入的歷史訊息讀取能力，在送出前與本輪 live messages 合併、依 ID 去重。
- `src/app/types.ts`、`AGENTS.md`、`design/data-model.md`：記錄訊息持久化與暫存 assistant 的資料契約。
- `package.json`、`package-lock.json`：移除不再使用的 `use-stick-to-bottom`。
