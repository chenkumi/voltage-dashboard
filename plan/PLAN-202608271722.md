# Plan

將 streaming runtime 與 UI 樹切離，使每個 chunk 只更新
`ChatStreamController` 與最新 assistant 訊息的 `MessageView`。
`AssistantChatWindow` 僅在持久化或暫存訊息 ID 集合變化時更新，
不再接收或掃描 `useChat.messages`。

> 本計畫請使用 execute-plan 技能執行。Checkbox（`- [ ]`）語法為追蹤格式。

## Scope

- In:
  - 以 event emitter 實作 `${message.id}-updated` 局部訊息更新。
  - `useChat` 移至無 UI 輸出的 controller component。
  - MessageList 僅訂閱 persisted IDs 與 transient streaming IDs。
  - 保留既有 IndexedDB、完成才持久化、abort/error 捨棄 partial assistant 的生命週期。
  - 補齊 runtime 與 ID 合併的單元測試。

- Out:
  - 不加入 `useChat` throttle。
  - 不變更 Markdown renderer、WebMCP tools、iframe 或 IndexedDB schema。
  - 不改變模型、transport 或歷史訊息送入 Agent 的行為。
