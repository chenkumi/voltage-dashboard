# Plan：將 Voltage Dashboard 重構為 Agent 可協作的商品管理系統

本計畫將目前偏展示用途、資料彼此分離的 Products／Catalog Intake，整合為真正可新增、查看、編輯、發布與封存的商品管理模組。完成後，外部 Agent 可自行讀取第三方商品頁，再透過 WebMCP 開啟並填寫既有商品編輯器；所有最終儲存與發布仍由使用者在頁面完成。

> 本計畫請使用 `execute-plan` 技能執行。Checkbox（`- [ ]`）為追蹤格式。

## Scope

### In

- 全站改為緊湊、功能優先的企業後台框架。
- 建立統一、可持久化的商品資料來源。
- 商品清單、詳細、新增與編輯路由。
- 商品圖片、描述、長短廣告文案、自由規格與匿名化評價。
- 商品草稿、發布、封存與還原。
- Products、Inventory、Dashboard、Reports 與 WebMCP 共享商品資料。
- 外部 Agent 導覽、讀取表單與填寫表單的 WebMCP tools。
- 移除 Catalog Intake 商品候選與商品 Approval 流程。
- DummyJSON 資料來源標示與隱私清理。

### Out

- Hono 後端或其他伺服器。
- 由 WebMCP executor 抓取 PChome 或其他第三方網頁。
- 內建 AI、Chat Room、Agent runtime 或廣告文案生成服務。
- Agent 直接儲存、發布、封存或刪除商品。
- 商品永久刪除。
- 評價新增、修改或回傳評論者身分資料。
- 訂單建立、付款、取消、退款等高風險操作。
- Orders、Customers、Operations Cases 的業務功能擴充。

## 已確認產品契約

以下內容將 Draft 1–6 的已確認結果完整保存在計畫內，執行與驗收不依賴對話紀錄。

- 商品資料：`Product` 包含數字 ID、唯一 SKU、標題、品牌、分類、價格金額、原生幣別
  （USD／TWD）、庫存、狀態（draft／published／archived）、描述、短廣告文案、長廣告
  文案、圖片、自由規格、唯讀評價、建立時間及更新時間。DummyJSON 種子一律標為 USD；
  外部 Agent 從 PChome 等來源整理的資料可按來源填入 TWD，系統不得自行臆測匯率。
- 圖片與規格：圖片為可排序 HTTPS URL 清單且恰有一張主圖；規格為可排序的
  `{ title, value, unit }` 清單，其中 title 與 value 必填、unit 可空白。
- 評價與隱私：評價只保存並顯示 rating、comment、date；匯入前移除 reviewerName、
  reviewerEmail 及其他評論者識別資料，文字以純文字呈現。
- 商品狀態：新增頁可「儲存草稿」或在完整驗證通過後「發布商品」；編輯頁可儲存
  變更、發布草稿、封存與還原。封存是可逆狀態，不提供永久刪除；還原回封存前狀態。
- 商品清單：主畫面提供搜尋、分類、狀態、庫存篩選、分頁、列勾選及批次封存；每列
  顯示主圖、可開啟詳細頁的名稱、SKU、分類、含幣別價格、狀態、庫存、更新時間，以及
  查看、編輯、複製、封存操作。
- 商品詳細：以商品圖庫與基本資料為首屏，後續呈現商品內容、自由規格、短／長廣告
  文案及評價；提供編輯、複製、封存或還原入口。
- 商品編輯器：`/products/add` 與 `/products/edit/:productId` 共用同一編輯器，包含基本
  資料、價格與幣別、庫存、圖片、描述、短／長廣告文案、自由規格、驗證摘要及預覽。
  Agent 只改變尚未提交的 editor state，repository mutation 只由使用者頁面按鈕觸發。
- 後台框架：全站使用緊湊 Header（breadcrumb、頁名、狀態、頁面 actions），不顯示
  eyebrow、slogan、Demo、Agent、WebMCP 或作品說明。側欄依序分為營運總覽、商品管理、
  訂單與客戶、營運管理、分析；移除 Catalog Intake。全站列保留搜尋入口、通知、語言與
  帳號區域，DummyJSON 來源放 Footer、資料說明或 About 入口。
- WebMCP 工具：全站可 discovery 商品搜尋、單筆查詢、分類清單與商品頁導覽工具；只有
  add／edit 頁 discovery `get_product_editor_state` 與 `apply_product_editor_draft`。
  導覽工具只切換頁面，填表工具只更新 editor state；不得提供 fetch、scrape、generate、
  save、publish、archive 或 delete product tools。外部 Agent 自行讀取第三方頁面後，再將
  整理結果填入本系統。
