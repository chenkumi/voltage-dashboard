# Plan

本次重構將商品頁確立為營運清單的基準，讓商品、庫存、訂單與顧客頁共用一致的搜尋工具列、進階篩選、結果摘要、表格與分頁；Dashboard 與各營運頁的統計卡也會統一成 shadcn Card 基底的專案共用元件。完成後，桌面畫面能以單列高頻條件保持緊湊，手機則透過 Search＋Filter Popover 操作完整篩選，不再出現欄位格式與版型各自為政的情況。

> 本計畫請使用 execute-plan 技能執行。Checkbox（`- [ ]`）語法為追蹤格式。

## Scope

- In:
  - Dashboard、Products、Inventory、Orders、Customers 的統計卡與清單頁視覺一致化。
  - 共用 Metric、搜尋工具列、Select、Filter Popover、作用中條件、List Panel 與分頁元件。
  - 桌面單列搜尋與 3–4 個常用條件。
  - 桌面 More Icon Button 與手機 Filter Icon Button。
  - 進階篩選的暫存、取消、清除、驗證與套用流程。
  - 商品清單新增排序選項。
  - 跨頁 RWD、keyboard、focus、ARIA 與狀態呈現。
  - 移除被共用元件取代的重複 KPI、CSS 與翻譯。
- Out:
  - 不改變 Product、Commerce 或 Inventory Repository 資料結構。
  - 不改變既有 WebMCP tool 名稱、schema、executor 或安全邊界。
  - 不改變訂單唯讀、庫存人工調整及客戶人工 mutation 規則。
  - 不修改詳細頁的業務內容與資料計算。
  - 不引入後端或新的表格框架。
  - 手機表格不改成卡片列表，仍採語意化表格與水平捲動。
