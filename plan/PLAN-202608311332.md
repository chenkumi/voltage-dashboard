# Plan

修正實機測試發現的 WebMCP 導覽同步、Returns 工具串接與商品草稿阻塞問題，並補齊退款流程 fixture。完成後，Agent 能可靠地跨頁操作安全工具，使用者可恢復草稿，且下一輪可驗證退款計算與核准詳情的正常流程。

> 本計畫請使用 execute-plan 技能執行。Checkbox（`- [ ]`）語法為追蹤格式。

## Scope

- In:
  - route-aware WebMCP 工具同步與 Agent 提醒。
  - `search_returns` 與後續 RMA 工具的 identifier 契約一致性。
  - 可恢復、自動保存的商品編輯草稿。
  - RMA calculation、pending／returned／pending-execution approval fixture。
  - 單元、workflow 與 Codex 內建瀏覽器實機驗證。

- Out:
  - Agent 執行發布、資格決定、驗貨、退款核准或退款。
  - 放寬任何個資、付款資料與安全 SQL 邊界。
  - 重構未受本次測試影響的 Orders、Inventory、Customers 或 Reports 功能。
