# Plan

將已核准的 [Returns／Refund Approvals 系統模型](C:/projects/webmcp-agent/docs/RETURNS-RMA-SYSTEM-MODEL.md) 落實成具備持久化、逐品項驗貨、確定性全額退款、人工核准與退款結果紀錄的完整 RMA 系統。實作會先建立正確的訂單金額與狀態契約，再依序完成 Repository、UI、WebMCP、Dashboard 與 Reporting，最後移除沒有業務結果的舊 Operations workflow。

> 本計畫請使用 execute-plan 技能執行。Checkbox（`- [ ]`）語法為追蹤格式。

## Scope

- In:
  - 雙來源 RMA、固定政策資格審查、退貨授權、收貨、逐商品驗貨。
  - 驗貨通過品項的全額退款計算。
  - 單級 Refund Approval。
  - 退款核准與外部退款結果紀錄分離。
  - 退貨商品重新入庫的人工確認與防重處理。
  - Returns、Refund Approvals、Orders、Dashboard、Reporting 整合。
  - WebMCP 安全查詢、導覽、草稿填寫及 verifier。
  - 舊 Operations Cases／Approval Inbox 退場與相容 redirect。
- Out:
  - 換貨、補寄、維修、顧客退貨前台。
  - 真實物流或支付 API。
  - 多級核准、部分金額退款、人工改價及跨幣別換算。
  - Agent 提交、收貨、驗貨、核准、退款或其他最終操作。

- `src/app/webmcp/operations/` 中的泛用 Case、Review、controller、tools 與頁面。
- 固定退貨政策搬至 `returns/`。
- 被 Product tools 共用的內容安全邏輯搬至中立的共用模組，避免保留假的 Operations 相依。
