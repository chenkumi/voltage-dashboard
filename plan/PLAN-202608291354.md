# Plan

將現有 Voltage Dashboard 擴充為可展示跨模組行政流程的電商營運自動化平台。保留既有 Smart Dashboard、庫存與報表能力，新增商品上架草稿、營運異常案件、售後建議與人工核准流程，讓 Agent 能完成低風險準備工作，而所有高風險最終操作仍由使用者在頁面內執行。

> 本計畫請使用 execute-plan 技能執行。Checkbox（`- [ ]`）語法為追蹤格式。

## Scope

- In:
  - 新增 Catalog Intake、Operations Cases、Approval Inbox 三個 Outlet 頁面。
  - 建立商品候選資料、商品草稿、訂單異常、退貨案件、審核項目及稽核紀錄。
  - Agent 可搜尋資料、建立／更新草稿、分類案件、判斷退貨資格及產生客服建議。
  - 使用者可在頁面中發布商品草稿、核准處理方案或執行模擬最終操作。
  - 新增對應 WebMCP tools、skills、route-aware instructions 與完成驗證。
  - 修正既有訂單／客戶 tools 可能回傳穩定帳戶識別碼的問題。
  - 保留既有 SQL、Report Canvas、query cache 與 runtime 隔離限制。
  - 使用共用、記憶體內的 seeded demo workspace；跨路由保留，頁面 reload 後重設。

- Out:
  - 真實供應商網站爬取或外部搜尋。
  - 真實商品發布、付款、退款、取消或確認訂單。
  - 個資、地址、帳戶識別及付款資料。
  - 後端、登入、權限角色、多租戶與跨裝置持久化。
  - Storefront、Chat Room、內建 Agent 或多網站 registry。
  - 擴充 SQLite Agent database 的既有四個 curated datasets。
  - 任意 HTML、程式碼 widget 或 Agent 自動提交高風險表單。
