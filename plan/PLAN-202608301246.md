# Plan：建立營運資料查詢與分析中心

本階段將 Inventory、Orders、Customers 從靜態展示升級為可實際操作的企業後台模組，並建立安全的跨模組分析資料。完成後，使用者可以查看庫存歷史、訂單明細及維護客戶；外部 Agent 則能透過 WebMCP 查詢匿名營運資料、比較趨勢並產生區域、客群、訂單與庫存整合報表。

> 本計畫請使用 `execute-plan` 技能執行。Checkbox（`- [ ]`）為追蹤格式。

## Scope

### In

- 純前端、IndexedDB 持久化的合成訂單與客戶資料。
- 至少 13 個月的確定性訂單、銷售及庫存歷史。
- 庫存搜尋、篩選、排序、分頁、歷史趨勢、前期比較及人工調整。
- 訂單搜尋、篩選、排序、分頁、快速展開及詳細頁。
- 客戶搜尋、篩選、詳細、新增、編輯、停權、復權、標籤及備註。
- WebMCP 安全查詢、匿名分析及頁面導覽。
- 移除 Agent 直接修改庫存的能力。
- 匿名化 Orders、Customers、Inventory reporting datasets。
- 區域、客群、付款結果、履約狀態、商品銷售及庫存風險報表。
- 更新 AGENTS、營運文件、skills、隱私測試及瀏覽器驗收。

### Out

- Hono 後端、登入、權限或多人同步。
- 真實客戶、訂單、付款或物流服務。
- Agent 新增、修改、停權或復權客戶。
- Agent 調整庫存。
- 建立、修改、取消、退款、付款或確認訂單。
- 原始個資、地址、客戶備註、付款 token 或完整付款資料進入 WebMCP／SQLite。
- 匯率推測或跨幣別直接加總。
- 採購單、供應商、倉庫調撥及退貨入庫子系統。
- 客戶硬刪除。

## Files

### 預計新增

- `src/app/webmcp/commerce-data/types.ts`：訂單、訂單項目、客戶、備註、活動與安全維度型別。
- `src/app/webmcp/commerce-data/commerce-seed.ts`：至少 13 個月的確定性合成客戶與訂單資料。
- `src/app/webmcp/commerce-data/commerce-repository.ts`：Orders／Customers Dexie repository 與人工客戶 mutation。
- `src/app/webmcp/commerce-data/commerce-store.ts`：React 可訂閱的營運資料 snapshot。
- `src/app/webmcp/inventory/`：庫存型別、歷史聚合、列表、詳細頁、調整 dialog、tools 與測試。
- `src/app/webmcp/orders/`：訂單 selectors、列表、詳細頁、tools 與測試。
- `src/app/webmcp/customers/`：客戶 selectors、列表、詳細、editor、validation、tools 與測試。
