# Plan

修正 Smart Dashboard 在工具失敗後仍產生誤導性完成訊息的問題。核心方向是讓 provider 錯誤以真正的 AI SDK tool error 傳回 Agent、提供可修正但不洩漏資料的錯誤分類，並保留一個不可再呼叫工具的最終摘要 step，確保 Agent 能解讀最後一批工具結果。

目前已確認相關 5 個測試檔共 98 項測試通過，`npm run typecheck` 也通過；完整的 LLM 對話流程仍需使用原始 prompt 實機驗證。

> 本計畫請使用 execute-plan 技能執行。Checkbox（`- [ ]`）語法為追蹤格式。

## Scope

- In:
  - 跨 iframe tool error 正規化與傳遞。
  - SQL 安全檢查的細分類與安全錯誤訊息。
  - Report tool schema 與 argument error 的可修正性。
  - Agent tool loop 的 step lifecycle log。
  - 預留最終摘要 step，避免最後一次 tool result 無人解讀。
  - Report skill 的完成驗證與異常回報規則。
  - 原始營運報表 prompt 的自動化與實機回歸驗證。
- Out:
  - 放寬個資、帳戶及付款資料安全邊界。
  - 支援任意 SQL literal、HTML 或程式碼 widget。
  - 多報表、持久化、發布與分享功能。
  - 更換 LLM provider 或模型。
  - 新增 Report Canvas 完成狀態 UI；本輪以實際 report state 與 Agent 回覆一致為準。
