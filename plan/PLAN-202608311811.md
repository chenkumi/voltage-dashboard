# Plan

修正第四輪實機測試確認的四項 Agent 可操作性問題：讓導覽後第一次 discovery 即取得完整的新頁工具、讓 SQL 錯誤可由 Agent 結構化處理、區分客群空資料與隱私抑制，並明確標示退貨資格試算不會寫入人工決策。完成後，Agent 能依單一、穩定的契約跨頁操作，不需額外等待或猜測錯誤語意。

> 本計畫請使用 execute-plan 技能執行。Checkbox（`- [ ]`）語法為追蹤格式。

## Scope

- In:
  - WebMCP route-specific tool 註冊完成訊號與 revision。
  - 所有 WebMCP 導覽工具等待目標 toolset ready 後才完成。
  - `execute_readonly_sql` 的安全結構化錯誤結果。
  - 客群隱私抑制 outcome。
  - 退貨資格試算的非持久化語意。
  - 自動化測試與內建瀏覽器實機回歸。
- Out:
  - 商品發布、庫存異動、訂單異動、RMA 提交、退款核准或退款執行。
  - 更改客群至少 5 人的隱私門檻。
  - 暴露原始 SQLite error、stack trace 或資料庫內部資訊。
  - 重新設計 Report Canvas 或營運頁面 UI。
