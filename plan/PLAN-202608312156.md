# Plan

將已確認的 Returns／Refund Approvals 六組 Draft 實作成一致的七階段售後流程。完成後，人工使用者可在清楚的階段式頁面處理 RMA、留下可持久化的審查紀錄；外部 Agent 則只能透過 WebMCP 讀取安全資料及更新目前帳號的可逆備註草稿，不會介入最終業務決策。

> 本計畫請使用 execute-plan 技能執行。Checkbox（`- [ ]`）語法為追蹤格式。

## Scope

- In:
  - 七階段 Returns 共用流程模型。
  - RMA 詳細頁與 Refund Approval 詳細頁重構。
  - 多人、多階段審查紀錄與自動儲存草稿。
  - IndexedDB schema migration 與目前登入帳號識別。
  - WebMCP 備註草稿工具、route discovery、版本錯誤及 skills。
  - 文件、翻譯、自動測試及內置瀏覽器實機驗證。
- Out:
  - Agent 發布或捨棄備註。
  - Agent 執行資格決定、收貨、驗貨、送審、退款核准或退款執行。
  - 支付、物流或其他後端 API。
  - 多級核准、部分退款、換貨及補寄。
  - 讓 WebMCP 讀取其他使用者的私人草稿或所有內部備註。
  - 清理工作樹中與本次重構無關的既有修改。
